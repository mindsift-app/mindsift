# Languages

MindSift speaks German, English, Spanish, French and Italian. German is the source language: texts are written in German first, every other language translates them. Background and decisions: [plans/mehrsprachigkeit.md](plans/mehrsprachigkeit.md); how it works: [architecture.md](architecture.md#languages).

## Where the texts live

| What | Where |
|---|---|
| Interface | `frontend/src/locales/<code>/<area>.json` (i18next, `{{placeholder}}`, plurals as `_one`/`_other`) |
| In-app help | `frontend/src/features/help/content/<code>.tsx` |
| Server texts (errors, mails, push, summary, columns, journal) | `internal/i18n/messages_<code>.go`, keyed by the German text, `{placeholder}` |
| Dates and times in server texts | `internal/i18n/format.go` |
| App description and shortcuts (`manifest.json`, `index.html`) | `staticTexts` in `internal/api/server.go`, translated through the server catalog |
| Sample data and help notes of new accounts | `internal/storage/seed.go` (German), `seed_en.go` (English, for every other language) |

## Adding a language

1. **Interface:** copy `frontend/src/locales/en/` to the new code and translate the values (keep the keys and `{{placeholders}}`). Add the code to `LANGUAGES` and `loaders` in `frontend/src/i18n/index.ts`.
2. **Help:** copy `features/help/content/en.tsx` and register it in `content/index.ts`.
3. **Server:** copy `internal/i18n/messages_en.go` to `messages_<code>.go`, translate the values (keep the German keys and `{placeholders}`), register it in `catalogs` (`messages.go`), add a date format to `format.go` and the code to `Supported` (`i18n.go`).
4. **Check:** `npx vitest run src/i18n` (every language has the German keys and placeholders) and `go test ./internal/i18n/` (every German server text has a translation, every supported language a catalog and date format).

A server text a catalog lacks shows in English; an interface text a language lacks shows in German.

## Rules for new code

- Interface: no fixed text in JSX, attributes (`title`, `aria-label`, `placeholder`) or messages; use `t('…')` or `i18n.t('area:…')` and add the key to every language.
- Server: write the German text through `writeError`, `tr`, `i18n.T(lang, …)` or `i18n.NewError` and add it to every catalog; the catalog test lists what is missing. Messages to a person use `userLanguage` (API) or `MessageLanguage` (store), MCP and OAuth use English.
